# 🎯 Objetivo

Desarrollar una API RESTful que permita gestionar operaciones básicas (CRUD) sobre una base de datos.

Tiempo de resolución: 48 hs.

# 🛠️ Requisitos técnicos

- Framework: .NET 8 (o superior)
- ORM: Entity Framework Core
- Base de datos: SQL Server o MySQL

# ⚙️ Alcance funcional

La API deberá contemplar operaciones CRUD sobre una de las siguientes temáticas (a elección):

- Gestión de inventario
- Gestión de usuarios
- Gestión de libros de biblioteca
- Otra temática similar (queda a tu criterio)

# ✅ Requisitos mínimos

- Implementación de operaciones CRUD completas
- Validaciones de datos
- Manejo adecuado de errores
- Al menos una prueba unitaria

# 📦 Entregable

Se deberá compartir un repositorio Git que incluya:

- Código fuente del proyecto
- Archivo README con:
  - Instrucciones claras para la ejecución del proyecto
  - Detalle de las pruebas realizadas

# ⭐ Valoraremos especialmente

- Buenas prácticas de desarrollo
- Organización y claridad del código
- Uso de patrones si corresponde
- Implementación dockerizada del proyecto (no excluyente, pero suma puntos)
